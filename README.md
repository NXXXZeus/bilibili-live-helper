# B站直播助手

一个原生 JavaScript 编写的 Chrome Manifest V3 扩展，提供直播间点赞辅助及可自定义的定时弹幕。

当前插件版本：**1.1.0**。本项目不是哔哩哔哩官方产品，与平台无关联。

## 功能

- 识别 `https://live.bilibili.com/数字房间号` 和 `/blanc/数字房间号` 页面。
- 支持赛事专题内同域直播 iframe；仅匹配网址不执行，必须找到实际直播控件。
- 每次访问进行最多 **40次点赞尝试**，默认模拟 K 键，也可手动切换页面点赞按钮模式。
- 发送间隔提供 **1至10分钟十个选项**，内容可输入文字或表情，默认 **2分钟**及**🫡**。
- 保存内容或间隔后重新计时，配置在当前 Chrome 本地保留，后续调整无需刷新直播间。
- 多标签同房间去重，支持全部暂停、分别关闭点赞/弹幕、指定房间及手动重置点赞计数。
- 不覆盖直播间草稿，不抢焦点；打字、输入法或输入框聚焦时暂缓操作。
- 操作结果未知时不盲目补发，也不批量追补电脑休眠或暂停期间错过的弹幕。

## 安装

需要 Google Chrome 106 或更新版本。

1. 下载仓库源码 ZIP 并解压，或通过 Git 克隆仓库。
2. 打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的仓库目录。
4. 登录自己的哔哩哔哩账号，打开直播间，刷新一次。
5. 点击浏览器工具栏的插件图标，查看识别状态和尝试次数。

**不要直接打开 `popup.html` 作为插件使用。** 它是扩展的弹窗，只能在扩展上下文中调用 Chrome 接口。

本仓库无需 npm 依赖或构建步骤，也未发布到 Chrome 网上应用店。

## 自定义弹幕

1. 打开插件弹窗。
2. 在“发送间隔”下拉中选择1、2、3、4、5、6、7、8、9或10分钟。
3. 在旁边“弹幕内容”输入框填入文字或表情。
4. 点击“保存设置”。

首次发送等待所选间隔，不立即提交；后续以实际尝试时间为起点再次等待。修改内容或间隔后，已识别房间会从保存时重新计时，点赞计数保持不变。重复保存相同设置或只暂停，不重设弹幕计时。已经预约或正在提交的一次弹幕可能仍使用原内容，无法撤回。

输入不得为空、全空格或多行，插件上限为 **200个 Unicode 码点**，不静默截断；这不是平台实际可发送长度承诺。账号、等级、房间或平台规则可能有更短限制。

所有自定义内容只按字面文本处理，不作为 HTML 或脚本执行。设置为全局配置，作用于指定范围内的所有已识别房间。

## 点赞与保护机制

模拟 K 会生成 `keydown`、`keypress`、`keyup` 事件，`key=k`、`code=KeyK`、键码75。这些是浏览器合成事件，`isTrusted=false`，不等同于物理键盘。网页可能不认可，计数只代表尝试次数，**不是点赞、续牌或经验到账证明**。

若 K 模式不生效，可暂停，改为“点击页面点赞按钮”，保存、启用，然后按需选择“重做40次”。按钮点击仍可能被平台拒绝。

直播间有草稿、正在输入或焦点停留在输入控件时暂缓；真实键盘/输入事件后至少等待5秒。发送失败后留下的弹幕草稿不会自动删除或反复提交，请检查页面状态后自行处理。

“每次进入”模式下，快速刷新不重新发送满40次；离开同房间超过90秒后在新文档重新打开视为新访问。同一文档的后台定时器延迟不会因此归零。“每天一次”模式只在当前浏览器会话内按北京时间日期累计，不跨浏览器重启保证去重。

## 更新已安装插件

更新本地仓库文件后，在 `chrome://extensions/` 点击本插件的重新加载，再刷新直播间一次。之后修改弹幕内容和间隔仅需点击保存。

重载插件会清空会话计数和计时，可能再次进行40次点赞；若不需要，可先关闭“自动点赞”。本地持久设置通常保留，卸载插件则会移除这些设置。

## 权限与隐私

清单只申请：

- `storage`：本地保存配置和浏览器会话状态。
- `https://live.bilibili.com/*`：识别并操作该域名下的直播间控件。

代码不读取 Cookie、密码、登录令牌或账号凭据，不调用平台私有接口、不加载远程执行代码、不向第三方回传配置。配置包含用户填写的弹幕文本、间隔和作用房间；会话记录包含房间号、时间、尝试次数和简短操作结果。操作结果可能包含本次自定义弹幕文字，均存储在本机 Chrome 扩展存储中。

## 运行限制与使用规则

- 后台标签可能被 Chrome 延迟或冻结，所选间隔是最低等待时间，不承诺秒级准时。
- 页面关闭、浏览器关闭、电脑休眠、断网时不能可靠执行；不修改系统睡眠设置或做额外保活。
- 仅识别部分明显休息提示，不保证完整判断是否开播。
- 网页 DOM 更新后可能需要更新选择器。
- 输入框清空不等于服务端送达，更不等于奖励入账。
- 自动操作、重复弹幕可能被平台限制。请遵守哔哩哔哩规则和直播间要求，不用于刷屏、广告、骚扰、虚假互动或规避平台限制；出现提示应暂停，不尝试绕过。
- 本项目不承诺续牌、等级或经验增长，不使用 debugger 或系统按键伪装真实硬件事件。

## 文件

- `manifest.json`：扩展清单。
- `background.js`：配置持久化、计时与跨标签去重。
- `content.js`：直播间识别、点赞与弹幕操作、输入保护。
- `popup.html`、`popup.css`、`popup.js`：设置界面。
- `test.cjs`：不联网的模拟环境测试。
- `LICENSE`：MIT许可证。

## 测试

在安装 Node.js 18 或更新版本的环境执行：

```sh
node --check background.js
node --check content.js
node --check popup.js
node test.cjs
```

当前 **23项离线测试**通过，包括1至10分钟首次/后续到期边界、配置校验、旧设置迁移、Unicode文本原样保留、保存后重计时、点赞计数保留、弹窗回读和草稿保护。测试会生成 `测试结果.json`，不包含真实账号状态。

离线测试使用模拟的 Chrome runtime/storage、DOM及计时器，**不是自动化的真实平台送达测试**。自定义配置版尚未完成真实账号、长时后台运行、不同账号长度规则或奖励入账的完整验收。已有使用成功反馈不代表所有环境或未来页面版本均可用。
